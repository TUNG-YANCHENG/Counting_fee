# 🏝️ 台東行程計算器

一個為台東潛水民宿設計的整合式費用計算工具，支援「潛水遊」「民宿住宿」「組合套裝」三大模式，提供複雜多人行程、靈活折扣、自動平日/假日判斷。

## ✨ 功能特色

### 🤿 潛水遊模式
- **自動查表**：依人數（1-8人）自動套用 Fun Dive 價目表
- **多種潛水活動**：岸潛、船潛、夜潛、Check Dive
- **裝備租賃**：自備/全裝/重裝，自動判斷半天/全天檔位
- **人數快速選擇**：1-12人按鈕快速設定
- **自動代號**：A, B, C... 自動帶入
- **多天行程**：每活動獨立勾選參加人員
- **靈活折扣**：每行費用可覆寫、全體折扣、自訂項目

### 🏠 民宿住宿模式
- **房型管理**：6種房型（六/五/四/三/兩人房 + 大白屋）
- **智能定價**：依「房型 × 入住人數 × 平日/假日」自動計算
- **日期選擇器**：自動判斷平日(日-四)、假日(五-六)及國定假日
- **加購行程**：
  - 三天二夜超值/套裝（含潛水/浮潛）
  - 四天三夜超值/套裝（含潛水/浮潛）
  - 自動計算機車差價（奇數人數時）
- **靈活添加**：自訂項目、折扣、其他費用

### 💾 資料管理
- **本地儲存**：所有資料存儲在瀏覽器 localStorage
- **草稿管理**：儲存/載入多筆常用報價範本
- **一鍵複製**：複製純文字報價，直接貼給客人

### ⚙️ 後台管理
- **潛水費用管理** (`admin.html`)
  - 即時編輯 Fun Dive 價目表
  - 編輯裝備租賃價格
  - JSON 匯出/備份
- **民宿價格管理** (`admin-residence.html`)
  - 編輯 6 種房型定價（平日/假日）
  - 編輯 8 種加購行程定價
  - 即時生效，無需重新整頁

## 🎯 使用流程

### 🤿 潛水遊模式

**第一步：選擇人數**
- 點擊「1-12人」按鈕快速選擇
- 系統自動帶入代號 (A, B, C...)

**第二步：規劃行程**
- 輸入日期（如 9/25）點「新增一天」
- 選擇潛水活動類型（岸潛/船潛/夜潛/Check Dive）
- 勾選各活動的參加人員

**第三步：設定裝備**
- 每位潛水員選擇裝備方案（自備/全裝/重裝）
- 自動計算配重保險費和半天/全天檔位
- 支援每行費用覆寫

**第四步：確認費用**
- 自動計算所有費用
- 支援整體折扣、自訂項目
- 「複製報價文本」直接貼給客人

### 🏠 民宿住宿模式

**第一步：選擇入住日期**
- 用日期選擇器選「入住日」和「退房日」
- 系統自動判斷平日/假日及計算住宿晚數

**第二步：選擇人數**
- 點擊「2-6人」按鈕選擇入住人數
- 自動列出可容納該人數的房型

**第三步：選擇房型或加購行程**
- **方案 A**：直接選「房型」（如六人房）
  - 自動計算該房型對應人數的平日/假日價格
- **方案 B**：選「加購行程」（如三天二夜超值行程含潛水）
  - 自動計算房費 + 潛水費 + 機車差價

**第四步：確認費用**
- 自動計算所有費用（房費 + 行程費 + 其他）
- 支援折扣、自訂項目
- 「複製報價文本」貼給客人

### ✨ 組合套裝模式（開發中）

## 🔧 後台管理

點擊「⚙️ 後台管理」按鈕進入：

### 修改 Fun Dive 價格
- 編輯 1-8人不同潛水類型的價格
- 變更自動應用到所有計算

### 修改裝備租賃價格
- 全裝、重裝、輕裝等設備的半天/全天價格
- 支援修改所有加購單品

### 修改基礎費用
- 船潛登船費、高氧瓶費、配重保險費等
- 點擊「重置為預設值」可恢復初始設定

## 💡 報價範例

假設 3 人潛水團隊，9/25-9/27 行程：

```
潛水人員:
A - 自備
B - 全裝租賃  
C - 重裝租賃

活動費:
  9/25 - 岸潛(1支) = 750 × 3 = 2,250
  9/25 - 船潛2趟 = 1900 × 3 × 2 + 船費1300 × 3 × 2 = ...
  ...

裝備費:
  A - 自備(配重保險) = 200 × 3 = 600
  B - 全裝租賃 = 1000 × 2 + 600 × 1 = 2,600
  C - 重裝租賃 = 700 × 3 = 2,100

合計: $XXXXX
平均每人: $XXXXX
```
