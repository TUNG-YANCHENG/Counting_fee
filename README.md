# 🤿 潛水費用計算器

一個為潛水教練/店家設計的專業費用計算工具，支援複雜多人行程、靈活折扣、設備多選。

## ✨ 功能特色

### 💰 費用計算
- **自動查表**：依人數（1-8人）自動套用 Fun Dive 價目表
- **多種潛水活動**：岸潛、船潛、夜潛、Check Dive
- **裝備租賃**：自備/全裝/重裝，自動判斷半天/全天檔位
- **靈活折扣**：每行費用可覆寫、全體折扣、自訂項目

### 👥 人員管理
- **人數快速選擇**：1-12人按鈕快速設定
- **自動代號**：A, B, C... 或 潛水員1, 2, 3...
- **每人獨立設定**：每人可選擇不同裝備方案

### 🗓️ 行程規劃
- **多天行程**：支援多天潛水活動
- **每個活動獨立勾選**：同一天內不同活動可有不同參加人員
- **彈性組合**：支援有人不下水、部分人參加的情況

### 💾 資料管理
- **本地儲存**：自動儲存到瀏覽器 localStorage
- **草稿管理**：儲存/載入多筆常用報價範本
- **一鍵複製**：複製純文字報價，直接貼給客人

### ⚙️ 後台管理
- **價格表編輯**：直接在網頁上修改 Fun Dive 與裝備租賃價格
- **實時生效**：修改價格即時反映在計算結果上
- **JSON 匯出**：匯出價格表用於備份或備份導入

## 🎯 使用流程

### 第一步：選擇人數
- 點擊「1人」到「12人」按鈕快速選擇
- 系統自動帶入代號 (A, B, C...)

### 第二步：規劃行程
- 輸入日期（如 9/25）
- 點「新增一天」
- 選擇潛水活動類型
- 勾選各活動的參加人員

### 第三步：設定裝備
- 每位潛水員選擇裝備方案
- 自備、全裝、重裝自動計算配重保險費
- 支援覆寫特價金額

### 第四步：確認費用
- 自動計算所有費用
- 支援覆寫個別行項或整體折扣
- 「複製報價文本」貼給客人

### 第五步：儲存草稿（可選）
- 點「儲存草稿」給常用行程命名
- 下次直接「載入」即可快速複製

## 🔧 後台管理

點擊「⚙️ 後台管理」按鈕進入：

### 修改 Fun Dive 價格
- 編輯 1-8人不同潛水類型的價格
- 變更自動應用到所有計算

### 修改裝備租賃價格
- 全裝、重裝、輕裝等設備的半天/全天價格
- 支援修改所有加購單品

### 修改基礎費用
- 船潛登船費、高氧瓶費、配重保險費等
- 點擊「重置為預設值」可恢復初始設定

裝備費:

  B - 全裝租賃 = 1000 × 2 + 600 × 1 = 2,600
  C - 重裝租賃 = 700 × 3 = 2,100

合計: $XXXXX
